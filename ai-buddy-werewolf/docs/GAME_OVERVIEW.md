# AIバディ人狼 — 企画概要

## 仮タイトル / キャッチコピー

**AIバディ人狼** — 裏切りか、信頼か。2人で力を合わせて生き残れ。

本作が目指す体験は、**人間同士のチャットで起きやすい威圧・専門用語・暴言からプレイヤーを守りながら、心理戦・騙し合い・推論の深さは失わない人狼**である。主人の入力を選択式にし、公開討論をバディへ任せることで「対人チャットは怖いが、本格的な人狼の面白さは味わいたい」人も参加できる入口を作る。

## ゲームの核

本作は人狼ゲームをベースにした、**人間プレイヤー(主人) + AIバディ**の二人一組の心理ゲームである。

通常の人狼では人間自身が討論・推理・投票を行うが、本作で実際に円卓で討論し、質問し、嘘をつき、推理し、最終投票を行うのは**AIバディ**である。人間は全体を俯瞰しながら、**限られた回数の助言**だけをバディへ送る。

**人間の助言は命令ではない。** AIバディは以下を総合して自分自身で最終判断する。

- 公開討論 / 他AIの発言
- 自分の役職・確定情報
- 自身の推論(内部評価)
- 主人からの助言
- 主人との親密度(内部設定名は `trust`)

主人がAを疑っていても、バディがBをより怪しいと判断すればBへ投票しうる。この「**人間はAIへ良い問いや情報を渡すが、最後に決めるのはAI自身**」という構造が本作の核であり、Phase0で検証したい対象である。

## 世界観

プレイヤーとバディは「二人の結束力を試す」という奇妙なお触れに導かれ、呪われた村へ入る。対になった勾玉を手に取ると呪いが発動する。

- 人間プレイヤーは**呪いの断頭台**へ拘束される
- AIバディは**呪いの円卓**へ拘束される
- 円卓側だけが討論・質問・裁判へ直接参加できる
- 断頭台側は全体を観察できる
- 二人は勾玉を通じて、限られた助言だけを送れる
- **円卓側が処刑されれば、二人とも死ぬ**

ゲーム世界の中では「AI」と呼ばない。AIバディはプレイヤーの親友・相棒・バディである一人の人物として扱う。

参加した二人組の一部は勾玉の呪いによって**《狼憑き》**になる。狼憑きになった場合、人間とAIバディの両方が同じ狼陣営になる。狼憑きが複数組いる場合、狼同士は最初から仲間を認識する。

(Phase0では世界観は簡単なテキスト表示のみ。演出・画像・アニメーションは対象外)

## 主人とAIバディの役割

| | 主人(人間) | AIバディ |
|---|---|---|
| 討論・公開発言 | ✘ 観察のみ | ○ 順番に発言 |
| 役職スキルの結果 | ○ **主人だけに届く** | ✘ 共有されるまで知らない |
| 討論中の助言 | ○ 1日1回・選択式 | 受け取って判断材料にする |
| 裁判の投票 | ✘(意思表示のみ) | ○ **最終投票を決める** |
| 夜襲(狼) | 提案のみ | 狼AIが評価し、複数狼は統合して決定 |

## 確定情報と主観情報

- **主観情報**(「私はAが怪しいと思う」「Bを襲うべきだ」): 親密度が高いほど、バディは自分の推理と異なっていても主人の意見を意識的に優先する。これは正解率の評価ではなく、信頼関係を行動へ反映する仕組みである。MAXでも固定加算のため100%服従にはならない。
- **確定情報**(占い結果など、ゲームシステムが保証する事実): 主人が「確定情報の共有」を使った場合のみバディに登録され、**親密度補正の対象外の事実**として扱われる。ただし、それを公開するか・伏せるか・いつ使うかはAIが判断する。

## 1日の流れ(討論・裁判・夜襲)

1. **朝**: 前夜の襲撃結果の発表
2. **冒頭討論**: まず生存バディだけで1回ずつ公開発言し、主人は口を挟まず各自の初期仮説を見る
3. **主人の相談**: 冒頭討論を読んでから、主人が1日1回だけ選択式の助言を送る
4. **応答討論**: 助言を受けたバディたちが再度話し合う。質問指定の場合は、質問者→指名された相手の単独回答→質問者の受け止め→周囲の反応という順で進む
5. **裁判**: 各主人が「自分なら誰を処刑するか」を選択(意思表示)。その後、各バディが自身の評価+親密度補正で最終投票。最多得票を処刑(同数はシード付きランダム)
6. **夜**: 占い役AIが占い先を決定(結果は主人だけへ)。狼主人は襲撃提案、狼AIは襲撃優先度を評価し、複数狼なら正規化合算で統合して襲撃

勝敗: 市民陣営は狼憑き全滅で勝利。狼陣営は狼数≧市民側人数で勝利。最大日数到達で引き分け(Phase0仮ルール)。

## 3能力(推論力・虚言力・親密度)

- **推論力**: 発言を額面通り受け取る段階から、投票整合・便乗検知・複数仮説・身内切り想定などの観点を10ポイントごとにアンロックしていく。正解率ではなく「使える推論観点の広さと精度」
- **虚言力**: 最低限の否定しかできない段階から、曖昧化・部分的真実・もっともらしい理由・一貫性維持・身内切り・誘導などの欺瞞技術をアンロックしていく。高くても必ず騙せるわけではない
- **親密度**: 主人の主観情報・提案をどれだけ優先するか。内部設定名は `trust`。主人が客観的に正しい確率ではなく、バディが関係をどれだけ大切にするかを表す。内部的には提案対象への加算ボーナス(補正関数は設定で交換可能)。**確定情報は親密度の対象外**

人格(名前・口調・キャラクター性)は「どう表現するか」にのみ影響し、能力とは分離する。

## Phase0で守るべき原則(削ってはいけない核)

1. **主人だけが持つ情報**: 占い結果はまず主人だけに届く。共有した場合のみAIが知る
2. **討論中の助言は1日1回**、選択式(自由文章入力なし)
3. **最終投票はAIバディが決める**: 主人の裁判選択は意思表示であり直接の一票ではない。主人とAIの選択が異なることを許容する
4. **内部スコアは試合中に公開しない**: 怪しい度・襲撃優先度・仮説などは試合後のリプレイ/分析画面でのみ確認できる
