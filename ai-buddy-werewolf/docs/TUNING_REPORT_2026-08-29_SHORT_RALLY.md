# 短文ラリー・攻め筋分散 調整レポート（2026-08-29）

## 目的

9組Live AIで確認された次の問題を、テンポを落とさず改善する。

- セバスなどの長い前置きで会話を追いにくい
- 複数バディが「具体的な根拠がない」「自分の見立てがない」と同じ攻め筋を繰り返す
- 主人の介入が1日1回だけで、議論へ参加した実感が薄い
- 指名質問への回答前後にも重い評価コールが入り、ラリーが遅い
- 誰が誰へ返したのか、モバイル画面で追いにくい

## 採用した調整

1. バディごとの観察担当を決定論的に分散
   - 回答回避、二者比較、発言と投票の整合、同意の時機と新規根拠、疑い始めた時機、反対仮説、庇い・距離取り、身内切り、焦点移動を能力値に応じて割り当てる
   - 同じシードでは再現し、別シードでは担当を回転する。結論の一致は禁止せず、同じ理由・役割・言い回しだけを避ける
2. 発言を原則1〜2文へ短縮
   - 人格は一人称・語尾・短い感情だけへ反映し、長い執事の前置きや全員の要約を禁止
   - Live構造化出力とブラウザ検証を最大120文字にし、ゲームコアにも文末優先の安全網を置く
3. 指名質問の高速化
   - `answer` / `follow_up` は、当日かつ主人の新入力より後に作られた討論評価だけを再利用し、通常は発言コール1回で返す
   - 前日評価・裁判/夜評価・助言前評価は再利用しない
4. 主人相談を本格9組で1日2回へ
   - 冒頭後に1回、応答討論が3発言進んだ後に追加1回
   - 質問→回答→受け止めの途中では相談を割り込ませない。見送りも1機会として残数へ反映する
5. モバイル表示
   - 名前を色付き `@名前`、指名回答を「↩ 名前への返答」で表示
   - 相談説明の重複を減らし、シートへ明示的な閉じるボタンとEsc操作を追加

`standard-nine`、6試合、seed `mari-short-rally-final-*`。モックは文章品質ではなく進行回帰の確認用である。

| 指標 | 結果 |
|---|---:|
| 完走 | 6 / 6 |
| 勝敗 | 市民3 / 狼3（n=6のためバランス結論には使わない） |
| 公開発言 | 1,134 |
| 平均 / P95 / 最大文字数 | 33.2 / 57 / 79 |
| 120文字超過 | 0 |
| 完全文面ユニーク率 | 36.2% |
| 「具体」/「理由がない」 | 0 / 0 |

初戦の7人の冒頭意見は、質問への正面回答、同意への新規根拠、疑い集中への便乗、疑い先変更、二者比較などへ分散し、完全一致は0件だった。全発言では、時機50件、同意・便乗57件、質問・回答420件、疑い先変更53件、庇い・距離取り10件、投票83件が現れた。旧モックの7/9同型からは大きく減ったが、モックの定型性そのものは残るため、最終判定はLiveで行う。

## 候補版Live比較

現時点では未確定。ローカル候補版から既存の認証先へ愛言葉を送る操作について、利用者の実行時確認を得た後に次を同条件で測る。

## 現時点の判断

ロジック、モック、型、秘密分離の回帰は解消できている。特に「結論を無理に散らす」のではなく、「同じ結論でも別の公開根拠を要求する」設計にしたため、確定情報がある局面で人工的な逆張りを起こしにくい。

ただし、Liveモデルが実際に観察担当を使い分けるか、短文化で推論の密度が落ちないかは未検証であり、候補版Live測定までは完成判定に含めない。
