# 短文・速度リズム調整レポート（2026-08-30）

## 結論

公開発言を「キャラの長台詞」から「結論先行の短いラリー」へ変更した。通常は52文字以内、絶対上限は60文字とし、390px画面でおおむね2〜3行に収める。人格は一人称・相手への敬称・最後の語尾のうち1〜2個へ限定し、内容のない相づち、儀礼的な共感、礼儀だけの前置き、自己説明、今後の抱負を削る。判断が変わった理由になる同意や納得は残す。

## 画像で長文が出ていた理由

画像の公開サイトは `deploy.json` 上の `sourceCommit=35bf2dc4c8d1838631e72f02b0c5792fd533cdcc` で、現在の短文調整より前のビルドだった。この旧版は発言を4〜6文まで許し、公開Edgeにも現在の60文字上限がなかった。UIが複数発言を結合したのではなく、モデルが一度に長文を返していた。

設定画面で保存した旧プロンプトがブラウザに残る場合にも備え、速度・文字数・禁止用語の契約は編集可能なテンプレートの外からも毎回追加する。既存の長い試合ログ自体は書き換えず、新しい設定で作成した試合から反映する。

## 変更内容

- 全経路（共有型、ブラウザLive、公開Edge、ゲームコア）の公開発言上限を60文字へ統一
- 質問36文字以内、回答40文字以内、反応46文字以内、役職を名乗る発言48文字以内を目安化
- 最初の約15文字で結論・直接回答・質問を提示
- 1発言1論点、公開根拠は1つだけ
- `CO / 白 / 黒 / 盤面 / 吊る / ロラ / ライン / 視点漏れ / 身内切り / 村目 / 狼目 / グレー / 縄 / 精査 / 囲い` を普通の日本語へ置換
- セバスは「短い執事敬語」に変更し、敬称と最後の語尾だけで礼節を表現
- 画面ラベルを「意見 / 質問 / 返事 / 反応 / 最初の説明」へ簡略化
- Live発言の出力上限を160 token、公開Edgeの強制上限を200 tokenへ縮小
- 60文字境界、文末優先短縮、ブラウザLive、公開Edge、セバス用プロンプトの回帰テストを追加

## モック比較（本格9組、6試合）

調整後の `standard-nine` を異なる6シードで完走し、公開発言1,188件を集計した。再現コマンドは `npm run simulate -- --preset standard-nine --matches 6 --seed mari-speed-rhythm-final3 --provider mock`（実際のシードは末尾 `-1`〜`-6`）である。

セバスは136発言で平均24.6文字、P95 41文字、最大46文字だった。確定情報の固定断定を除く全発言で、執事敬語または最後の語尾を1回だけ残した。

例:

- `私は狼憑きではございません。抽選だけでなく、次の返事を見てください`
- `直前の発言を聞いて評価を更新した。変えた理由はそこですな`
- `ユイは役職を明かすおつもりですか`

通常Webを390×844へ固定して実際の討論画面も確認した。セバスの46文字発言を含めて会話カードは2〜3行に収まり、横スクロールは発生しなかった。これは読み進めるリズムの確認であり、Liveモデルの応答時間を短縮したという測定ではない。

モックはテンプレート方式なので、同じ局面では同文が再登場する。Liveの前版 `.3` は16発言すべて異なる文面だったが、今回の `.4` はまだLive実測していない。短文化後の自然さ・同文率・実レイテンシーは、公開EdgeとPagesを更新した後、新規試合で確認する。
