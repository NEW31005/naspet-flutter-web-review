# 実験データ

## 現在の再現基準

- `intimacy-gradient-v1.json`
  - 生成: `npm run analyze:intimacy`
  - 42モック試合から裁判時の実AI基礎評価を抽出
  - 同じ局面へ主人案4定義、親密度50/80、最大影響値20/25/32/40を適用
  - 集計セルに加え、再計算できる全基礎スコアを `scenarios` に収録
  - SHA-256: `C71265226BA8D0AD72C688888233876439054E6306C5109F56BA1B2CB5142BEE`
  - `.gitattributes` でLFを固定し、OSの改行変換によるハッシュ差を防止

## 履歴資料

- `trust-controlled-experiment-summary.json`
  - Claude Code単独実験から受領した16セルの集計サマリー
  - 個別局面と生成スクリプトは含まれないため、完全再実行の基準には使わない
  - 当時の判断過程を追跡するために保存する

実験条件や集計方式を変えた場合は既存ファイルを上書きせず、`v2` など新しい名前で保存し、生成コマンド・シード・SHA-256を比較文書へ記録する。
